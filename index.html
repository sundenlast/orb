How it moves

      
The face is flat shapes wrapped onto a sphere and projected every frame, so the eyes foreshorten as the orb turns and slip out of sight past the edge.

      
The ball stays a perfect circle while it moves. It only jiggles for a moment when you poke it or when it changes reaction, and the face jiggles with it. Pokes also get a reaction of their own: one poke surprises it, a second makes it giggle, and a quick third leaves it dizzy before it goes back to what it was doing.

      
Switching reactions morphs each eye point by point over the morph duration, while shine, blush and tears pop in or shrink away.

    

  


  

    
Use it in your system
One file, no dependencies. Works in plain HTML, React, Vue or Svelte.

    

      

        
1. Include the script once (or copy orb-avatar.min.js into your project)


<script src="https://cdn.jsdelivr.net/gh/sundenlast/orb@main/orb-avatar.min.js"></script>

        
2. Drop in avatars


<orb-avatar reaction="working" color="#4fc9a8"
            size="40" mode="wander"></orb-avatar>

<orb-avatar reaction="needs" color="var(--brand)"
            mode="fixed" gaze="-20 10"></orb-avatar>

      

      

        
3. Drive it from your app


const orb = document.querySelector('orb-avatar');

orb.react('thinking');        // morphs to a reaction
orb.mode = 'wander';          // drift | follow | wander | fixed
orb.poke();                   // jiggle + poke reaction
orb.spin();                   // 360° turn
orb.lookAt(x, y);             // look at a point (client px)
orb.lookAt();                 // back to cursor / idle drift
const svg = orb.toSVG({ size: 256 });

orb.addEventListener('reactionchange', e =>
  console.log(e.detail.from, '→', e.detail.to));
orb.addEventListener('poke', e =>
  console.log(e.detail.count, e.detail.reaction));

      

      

        
Attributes

        

          
AttributeDefaultWhat it does

          
            
reactionidleOne of , or a name you registered.

            
color#f1efe9Body color. Any CSS color, including var(--token).

            
eye-color#141418Eyes and closed lids.

            
size64Ball diameter in px, or any CSS length. Setting width in CSS also works.

            
modedriftdrift sways gently. follow looks at the cursor. wander glances at random spots on its own and ignores the cursor. fixed holds still and looks at gaze.

            
gaze18 15Where the orb looks, as "yaw pitch" in degrees. Positive yaw is right, positive pitch is up. fixed locks to it; drift and wander use it as home.

            
jelly0.6How much the ball jiggles when poked or changing reaction, from 0 (none) to 1 (a lot). It never jiggles otherwise.

            
face-scale1.6Size of the face on the sphere.

            
morph0.42Seconds for one reaction to morph into the next. 0 switches instantly.

            
shadowoffFloor shadow that shrinks as the orb hops.

            
extrasonSparkles, zzz, hearts, sweat and the attention ring. Set extras="off" for dense lists. They use the text color around the orb.

            
staticoffDraw one frame and stop animating. Use it for long lists, thumbnails and exports.

            
labelreaction nameAccessible name for screen readers.

          
        

      

      

        
Add your own reaction


const { capEye, arcEye, blush } = OrbAvatar.shapes;

OrbAvatar.defineReaction('smug', {
  label: 'Smug',
  feats: () => [arcEye(-1), capEye(1, .14), ...blush()],
  motion: t => ({ roll: .15, pitch: .2, w: .5 }),
});

orb.react('smug');

      

      

        
Notes

        

          
Shapes go in named slots (L, R, hL, bL, tear…), which is how any reaction morphs into any other.

          
Off-screen orbs pause automatically, and all orbs share one animation loop. Reduced-motion users get the angle and expression without bouncing or drifting.

          
In React, render <orb-avatar reaction={state} /> and call methods through a ref.
